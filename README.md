# GestCD · Gestión de centros

Webapp para seguir la gestión de oficina de cada centro: fotos, KMZ, captura, Excel, informe (y firma del ingeniero en Málaga) hasta la subida a SharePoint.

- Al escribir el nº de centro muestra la línea y la dirección (`centros.json`).
- Integrada con [InformesConBT](https://jdevgpt.github.io/InformesConBT/): botón 📄 para abrir el centro y marcado automático del paso Informe al descargarlo.
- Instalable y sin conexión. Datos guardados en el navegador (copia de seguridad en Ajustes).
